# PornhubIntro

https://pornhub-intro.pages.dev

A PornHub-style intro generator.

Features:

- Offline. It renders the animation locally, thus no data is uploaded.

## Build

Clone this repository:

```shell
git clone https://github.com/BinTianqi/PornhubIntro.git
```

Install Deno. You can follow [the instructions](https://docs.deno.com/runtime/#install-deno).

Install dependencies:

```shell
deno install
```

Build:

```shell
deno task build
```
